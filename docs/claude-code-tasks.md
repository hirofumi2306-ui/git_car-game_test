## フェーズ3：軽タップ連打（無限継続）への対策 ★今回の新規要件

### 前提となる診断（コードで確認済み）
連打が成立する原因は3つ。
1. **ダメージが引きの強さに連動していない**：`fire()`（532行付近）で引き `v.p` が効くのは弾速 `sp`（`.45+.55*v.p`）だけで、`dmg` は車両性能とゲージ質（qm）のみで決まる。最小の引き（24px）でもフルダメージ
2. **発射間隔の制限がない**：`cdT` は開始カウントダウン専用で、通常発射にクールダウンが存在しない。指の速度がそのまま連射速度になる
3. **弱い弾でも「当たれば同じ」**：弾の寿命は3秒あり、遅い弾ほど画面に長く残って敵の降下とぶつかる

### T9. ダメージを引きの強さに連動させる（対策の核）
- 対象: `fire()` の `dmg` 計算（532行付近）
- 変更: `dmg` に引き係数を掛ける。式の目安：`dmg *= (0.3 + 0.7 * v.p)`（v.p=最小引きで約0.35倍、最大引きで1.0倍）。係数は定数 `PULL_DMG_MIN=0.3` として調整可能に。あわせて、ダメージ数字表示（T5）で弱いヒットは小さい数字になるため、プレイヤーが自然に「弱いとダメ」と学習できる
- 受け入れ条件: 最小引き連打ではドイツ勢（HP3）が従来の約3倍の発数でも倒し切れず、最大引きなら従来どおり2発で倒せる

### T10. 発射クールダウン（リロード）の導入
- 対象: 発射処理まわり全般。新規定数 `RELOAD_BASE`（目安0.55秒）
- 変更:
  1. 発射ごとにリロード時間を設け、その間は次の発射ができない。リロード中は発射台の周囲に円形ゲージで残り時間を表示する
  2. 車両ごとに連射性能があってもよい（既存の `tp.s` 等の強化と競合しない範囲で、初期は全車共通でよい）
  3. **PERFECT（ゲージ質 'P'）で撃った場合は次のリロードを半減**させる。ゲージ狙いが「強い・速い」の両面で最適解になるようにし、対策が単なる弱体化でなく「上手いプレイの優遇」になるようにする
- 受け入れ条件: 1秒間に撃てる回数が最大でも2回程度に制限され、PERFECT連打が最も効率の良いプレイになる

### T11. 最小引きの扱いを明確にする
- 対象: `pull()`（488行付近、現在 l<24 で不発）
- 変更: 引き不足で離した場合は不発のままにせず、発射台が小さく震える＋「もっと引いて！」の小さな表示を出す（フィードバックのみ。ペナルティは課さない）
- 受け入れ条件: 初見プレイヤーが「引く量が足りない」と気づける

### T12. 「硬い殻」敵の追加（連打の受け皿）
- 対象: 敵定義 `ET` とスポーン、判定（559行付近）
- 変更: 1ヒットのダメージが閾値（目安1.5）未満だとダメージが0になる「硬殻」属性の敵を1〜2種追加する。見た目で区別（金属質の枠）。通常の弱い連打では歯が立たず、強い引き＋PERFECTが要求される。出現は中盤以降のステージから
- 受け入れ条件: 軽タップ連打だけでは硬殻敵を倒せず、到達してライフが減る

# 第2部：ゲームを向上させる提案（設計案）

## 1. マンネリ対策：ラン中の「イベント」システム

現状もチャレンジにはステージギミック（gs：レーン/揺れ/ビート/風/群れ等）の仕組みがある。これを拡張し、**1ランの中でも20〜30秒ごとに小さな変化が起きる**ようにするのが最も効果的。

### 実装候補（効果が高い順）
1. **イベントルーレット**：一定時間ごとに抽選で1つ発動し、画面上部にバナー表示
   - 「追い風！」弾速アップ＆敵も速くなる（諸刃）
   - 「渋滞発生」敵の降下が止まる代わりに横に密集する（範囲攻撃の見せ場）
   - 「金ロゴ出現ラッシュ」高得点の金色敵が短時間だけ連続出現
   - 「濃霧」軌道プレビューが短くなる（上級者向けの緊張感）
   - 「フィーバー」10秒間スコア2倍＆リロード半減
2. **中ボスの乱入**：ステージ中盤に小型ボスが1体乱入し、倒すと大きな報酬（コイン/アイテム確定ドロップ）。今のボスは「ノルマ達成後」だけなので、ランの中盤に山場がない
3. **ラン中ミッション**：開始時に「コンボ8を達成せよ」「PERFECTを3回決めよ」等の小目標を1つ提示し、達成で即ボーナス。狙撃の敗因表示（T8）と同じく「今ランで何をすべきか」を与える
4. **天候・時間帯の変化**：ランの経過で背景が昼→夕→夜に変わり、夜は敵の輪郭が光る等、見た目の変化だけでも体感の単調さが減る（既存の進行連動背景の仕組みを拡張）

### 恒常コンテンツ側
- **デイリーギミック**：日替わりで「今日は風が強い日」「アーマー2倍の日」等の修飾子を全モードに付ける。既存のデイリー枠の置き換え先として自然
- **週替わりボス**：ボスのギミック（召喚パターン、弱点の車種）を週替わりにする

## 2. 「上手くなった感」を作る

- **PERFECT率の可視化**：結果画面に「PERFECT ○回／発射 ○回（○%）」を出す。ゲージ狙いの上達が数字で見えると、連打から卒業する動機になる（T9・T10の対策とも噛み合う）
- **ライバル表示**：プレイ中に「あと○点でランキング2位（Hirofumi）超え」のようなライブ表示を出す。ベスト表示（T4）の仕組みを応用でき、身内ランキングがある本作では身近な目標になる
- **チュートリアルステージ**：STAGE 0として「弱い引きでは倒せない敵→強い引きで倒す」「アーマー持ちを防がれる→PERFECTで貫通」を順に体験させる2分程度の導入を作る。監査B10（説明ゼロ問題）の根本対策

## 3. 連打対策の設計思想（友人の指摘への回答として）

対策は「連打を禁止する」のではなく「**連打が最適でなくなる**」形にするのが原則。T9（引き連動ダメージ）＋T10（リロード、PERFECTで短縮）＋T12（硬殻敵）の3点で、連打は「序盤の雑魚には通用するが、効率もスコアも悪く、中盤以降は詰む」プレイになる。一方でゲージを狙うプレイはダメージ・連射・貫通の全てで優遇され、上手いプレイが気持ちよくなる方向に寄せる。数値（PULL_DMG_MIN、RELOAD_BASE、硬殻閾値）は定数化してあるので、実際に遊んで「きつすぎる/緩すぎる」を調整する前提。

## 4. ロードマップ案

- **v3**：PERFECT率などの結果統計、ライバル表示、デイリーギミック
