## S1: Service Worker の追加（PWA化）

現状：manifest.json はあるが Service Worker がなく、毎回 10MB 超の音源・画像を読み直している。

実装：
- リポジトリ直下に `sw.js` を新規作成し、`index.html` の末尾で登録する（`'serviceWorker' in navigator` のガード付き。未対応環境では何もしない）。
- キャッシュ戦略：
  - **HTML（ナビゲーションと index.html）: Network First** — 取得できたらキャッシュも更新し、オフライン時のみキャッシュを返す。GitHub Pages の更新が次回読み込みで必ず反映されることを優先する。
  - **静的アセット（mp3 / png / jpg / manifest.json / アイコン）: Cache First** — 初回アクセス時にキャッシュへ。
  - **Supabase（*.supabase.co）への通信と GET 以外: 一切介入しない**（素通し）。
- キャッシュ名にバージョン定数を持たせる（例：`const CACHE_VER = 'lg-v1'`）。activate 時に旧バージョンのキャッシュを削除する。
- ゲーム本体の更新時は CACHE_VER を上げる運用であることを、sw.js の冒頭コメントに明記する。

受け入れ条件：
- 初回読み込み後、機内モード（オフライン）で再読み込みしてもログイン画面まで開ける。
- オンラインで新しい index.html をデプロイしたとき、次回読み込みで新しい版が表示される（古いキャッシュに固定されない）。
- Supabase のログイン・ランキング・スコア送信が従来どおり動く。

## S2: 90秒モードのフィニッシュ演出と同時終了

現状：`timeLeft` が 0 になっても演出がなく、急に終わる。

実装：
- `timeLeft <= 5.0` の間、画面中央に大きなカウントダウン数字（5→4→3→2→1）を1秒ごとに表示する。数字は拡大→フェードのアニメーション付き。残り時間表示も赤色に変える。
- 各秒にティック音を鳴らす（既存の sfx から流用。例：ping.mp3。なければ click.mp3）。
- `timeLeft` が 0 になった**その瞬間**にプレイを終了する。引いている途中・弾が飛んでいる途中でも即座に入力を無効化し、その時点のスコアで結果画面へ遷移する（ユーザー要望：「終了と同時にプレイが終了する」）。
- 対象は 90秒（time）モードのみ。他モードには影響させない。

受け入れ条件：
- 残り5秒から数字と音でカウントダウンが分かる。
- 0秒の瞬間に操作不能になり、結果画面のスコアはその時点のものと一致する。
- 0秒後に発射・得点が一切発生しない。

## S3: 必殺技システムの刷新（ユーザー確定案・2026-11-27差し替え）

現状（コード確認済み）：必殺技は `kill()` 内でコンボが10の倍数になると自動発動し、効果は全メーカー共通（全体にダメージ2.5／ボス3＋気絶0.8秒）。`ULT` テーブルにメーカー別の名前と色だけがある。これを以下の確定案に作り替える。**この節が正であり、以前の S3 案（PERFECT 5回・右下ボタン等）は破棄する。**

### ゲージの溜め方
- ゲージショットの判定と撃破で加算する：**PERFECT +10%、GREAT +3%、通常の撃破 +1%**（定数化：`ULT_PERFECT=10, ULT_GREAT=3, ULT_KILL=1`）。
- 100% で満タン1回分。満タンのまま溜め続けると**最大2回分（200%）までストック**できる。
- ゲージは1プレイごとに 0 から始まり、次のプレイに持ち越さない（セーブデータに保存しない）。
- コンボはスコアと演出だけに使い、必殺技の発動条件からは外す。**既存の「コンボ10の倍数で自動発動」は削除する。**

### 発動のしかた
- 100% 以上で「必殺技 READY!」と表示し、玉の周りのリングが金色に光る。
- **左下の赤い「ULT」ボタン**を押すと、そのとき装填している車（lastCar）の必殺技が発動し、100% を消費する（ストックが2回分あれば残り100%が残る）。
- 発動可能でないとき（100%未満）はボタンは半透明で、押しても何も起きない。

### 車ごとの効果（ULT テーブルの名前・色は既存のものをそのまま使う）
- TOYOTA「ハイブリッド・バースト」：全体にダメージを与え、ライフを1回復する
- HONDA「VTEC フルスロットル」：7秒間、弾の速度と威力が上がり、貫通する
- SUBARU「シンメトリカル・ストーム」：左右から挟み撃ちにして、画面を横断して貫く
- MAZDA「ロータリー・ブレイク」：回転する弾が、敵の間を8回跳ね回る
- NISSAN「GT-R ニトロブラスト」：画面の下から上へ、一直線に貫く
- SUZUKI「スイフト・ショック」：HPが2以下の小さい敵を一掃し、ほかの敵は長く気絶させる
- MITSUBISHI「ランエボ・サンダー」：最大10体へ、連鎖する電撃を飛ばす
- LEXUS「ラグジュアリー・ノヴァ」：全体を6秒間減速させ、バリアを2枚付ける
- DAIHATSU「ミラクル・コンパクト」：小さな弾が18発、降り注ぐ

実装のヒント：サプライヤー効果側に既に beam（貫通ビーム）、thunder（連鎖電撃）、shield（バリア）、heal（回復）、減速フィールド等の部品があるので、流用できるものは流用する。全体ダメージの数値は既存の ultimate() の値（通常2.5／ボス3、気絶0.8秒）を初期値とし、定数化する。
ガレージ画面（または図鑑）に、各車の必殺技名と説明を表示する。
サーバー側のスコア検証（submit_run の上限：撃破数 ≦ 時間×4+10、スコア ≦ 撃破数×400+2000×(ステージ+1)）を超える設計にしないこと。

受け入れ条件：
- PERFECT 10回で満タン（READY表示＋金リング）になり、GREAT や撃破でも少しずつ増える。
- ULTボタン（左下）で任意のタイミングに発動でき、メーカーごとに違う効果が発生する。コンボ10の倍数では自動発動しない。
- 200% まで溜めると2回連続で発動できる。プレイをまたいでゲージが残らない。
- 必殺技を使ったランでもスコア送信が 'implausible score' で弾かれない。
