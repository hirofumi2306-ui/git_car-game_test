対象リポジトリ: git_car-game_test / `index.html`（単一ファイルPWA）
前提：第1部（T1〜T15）、第2部（v2・v3）、天候・週替わりボスまで実装済み。
進め方：**1タスク1コミット**。コミットメッセージにタスク番号（S1など）を含めること。各タスクの受け入れ条件を自分で確認してから次へ。セーブデータ（SV）の形とSupabaseのRPC仕様は変えないこと。

## S1: Service Worker の追加（PWA化）

現状：manifest.json はあるが Service Worker がなく、毎回 10MB 超の音源・画像を読み直している。

実装：
- リポジトリ直下に `sw.js` を新規作成し、`index.html` の末尾で登録する（`'serviceWorker' in navigator` のガード付き。未対応環境では何もしない）。
- キャッシュ戦略：
  - **HTML（ナビゲーションと index.html）: Network First** — 取得できたらキャッシュも更新し、オフライン時のみキャッシュを返す。GitHub Pages の更新が次回読み込みで必ず反映されることを優先する。
  - **静的アセット（mp3 / png / jpg / manifest.json / アイコン）: Cache First** — 初回アクセス時にキャッシュへ。
  - **Supabase（*.supabase.co）への通信と GET 以外: 一切介入しない**（素通し）。
- キャッシュ名にバージョン定数を持たせる（例：`const CACHE_VER = 'lg-v1'`）。activate 時に旧バージョンのキャッシュを削除する。
- ゲーム本体の更新時は CACHE_VER を上げる運用であることを、sw.js の冒頭コメントに明記する。

受け入れ条件：
- 初回読み込み後、機内モード（オフライン）で再読み込みしてもログイン画面まで開ける。
- オンラインで新しい index.html をデプロイしたとき、次回読み込みで新しい版が表示される（古いキャッシュに固定されない）。
- Supabase のログイン・ランキング・スコア送信が従来どおり動く。

## S2: 90秒モードのフィニッシュ演出と同時終了

現状：`timeLeft` が 0 になっても演出がなく、急に終わる。

実装：
- `timeLeft <= 5.0` の間、画面中央に大きなカウントダウン数字（5→4→3→2→1）を1秒ごとに表示する。数字は拡大→フェードのアニメーション付き。残り時間表示も赤色に変える。
- 各秒にティック音を鳴らす（既存の sfx から流用。例：ping.mp3。なければ click.mp3）。
- `timeLeft` が 0 になった**その瞬間**にプレイを終了する。引いている途中・弾が飛んでいる途中でも即座に入力を無効化し、その時点のスコアで結果画面へ遷移する（ユーザー要望：「終了と同時にプレイが終了する」）。
- 対象は 90秒（time）モードのみ。他モードには影響させない。

受け入れ条件：
- 残り5秒から数字と音でカウントダウンが分かる。
- 0秒の瞬間に操作不能になり、結果画面のスコアはその時点のものと一致する。
- 0秒後に発射・得点が一切発生しない。

## S3: 必殺技システム

コンセプト（ユーザー発案）：ゲージショットで PERFECT を積み重ねると必殺技ゲージが溜まり、任意のタイミングで発動できる。車種（メーカー）ごとに効果が違う。

実装：
- チャージ：PERFECT 判定の発射1回で +1。`SP_MAX = 5` で満タン（定数化）。GREAT 以下では溜まらない。ラン開始時に 0、ラン中のみ保持（セーブデータには保存しない）。
- UI：画面右下（発射台の邪魔にならない位置）に必殺ボタン。現在の車のメーカー名／エンブレムとチャージ本数（5本のセグメント）を表示。満タンで発光＋脈動アニメーション。タップで発動し、チャージは 0 に戻る。
- 効果（メーカー別。既存の仕組みの範囲で実装し、数値は定数化）：
  - TOYOTA「ハイブリッド・オーバードライブ」：10秒間、リロード時間半減＋与ダメージ1.5倍
  - NISSAN「e-POWER ラッシュ」：画面内の全敵に固定大ダメージ（5）
  - HONDA「VTEC ゾーン」：8秒間、全ての発射が PERFECT 扱い（ダメージ・リロード・チャージ計算も PERFECT として処理。ただし必殺チャージ自体は増えない＝無限ループ防止）
  - MAZDA「ロータリー・ストーム」：前方の全敵に 1 秒間隔で 3 回の衝撃波ダメージ（各2）
  - SUBARU「AWD トラクション」：8秒間、敵の進行速度を半減し、スナイパー弾を無効化
  - MITSUBISHI「ラリーアーツ・チャージ」：画面幅を貫通する巨大弾を1発（ダメージ 10、硬殻も貫通）
  - SUZUKI「軽の意地」：現在の狙い方向へ高速弾を自動で 3 連射 × 3 セット（1発のダメージは通常弾の 0.8 倍）
  - DAIHATSU「ムーヴ・スマッシュ」：最も進んでいる敵 3 体に大ダメージ（6）
  - LEXUS「匠の一撃」：次の 1 発がダメージ 5 倍＋貫通＋硬殻無効になる（発射するまで保持）
- ガレージ画面（または図鑑）に、各車の必殺技名と説明を表示する。
- サーバー側のスコア検証（submit_run の上限：撃破数 ≦ 時間×4+10、スコア ≦ 撃破数×400+2000×(ステージ+1)）を超える設計にしないこと。必殺技で大量撃破しても上限に当たらない範囲の数値にすること。

受け入れ条件：
- PERFECT 5 回で満タンになり、ボタンが発動可能状態になる。GREAT では溜まらない。
- 発動するとメーカー固有の効果が発生し、チャージが 0 に戻る。
- HONDA の効果中でも必殺チャージが増え続けない。
- 必殺技を使ったランでもスコア送信が 'implausible score' で弾かれない。
