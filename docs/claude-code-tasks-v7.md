  `data:image/webp;base64,...` を生成して IM の該当キーへ差し込む。

## L2. ガチャ演出（単発）

現状の結果表示を、以下の流れの演出に置き換える。

1. 「まわす」→ `gacha_pull` の結果を受け取ってから演出開始
   （通信中は「まわしています…」程度の表示。演出と通信を混ぜない）。
2. 画面が暗転し、中央にカプセルが出現。カプセルの色は結果のレアリティ色（`RAR_C`）。
3. カプセルが左右に揺れる（0.8〜1.5秒。★が高いほど長く・大きく揺れる）。
   音は既存 sfx のみで工夫する（例: click を小刻みに鳴らす）。
4. 開封の瞬間: 画面シェイク（既存の shake 機構、強さはレアリティ連動）
   ＋ 放射状パーティクル ＋ レアリティ色のフラッシュ。
   sfx 目安: ★2 sparkle / ★3 sparkle＋ping / ★4 fanfare / ★5 fanfare＋cheer。
5. ロゴカードがバウンスしながら拡大して登場（scale 0.5 → 1.12 → 1.0）。
   カードには実ロゴ（L1）・社名・★・効果説明を表示。
   初回入手なら「NEW!」バッジ、重複なら「かけら×N に変換」を明示。
6. ★5 専用の格上げ: 虹色グロー ＋ スロー演出（0.3倍速で約1秒）＋ シェイク大。
7. 「閉じる」「もう一度まわす」ボタン。演出中の連打・二重実行は無効化する。
   単発の演出全体は3秒以内に収め、いつでもタップでスキップ可能にする。

## L3. ガチャ演出（10連）

1. カプセル10個を並べて表示し、タップで1個ずつ開封していく（演出は L2 の簡略版でよい）。
2. **表示順の工夫**: その10連の最高レアリティの結果は最後に開封されるよう表示順を並び替える
   （サーバーの結果そのものは変えない。あくまで開封順のみ）。
3. 「スキップ」ボタンで結果一覧へ直行できる。
4. 最後に結果グリッド（実ロゴ＋★＋NEW/かけら変換の内訳）を表示する。

## 制約（厳守）

- `gacha_pull` などサーバー側の仕様・料金・確率・冪等性には一切触れない。変えるのは表示と演出だけ。
- 新規の音声・画像ファイルは追加しない（使うのは `assets/logos/` と既存 sfx のみ）。
- スマホ縦画面でレイアウトが崩れないこと。
- 実装は L1 → L2 → L3 の順に、タスクごとにコミットを分けること。
