# Claude Code 指示書 v10: ルビー獲得の見える化 ＋ 図鑑デザイン刷新

前提: v9 までの実装が入っていること。タスクは K1 → K2 → K3 の順に、
タスクごとにコミットを分けること。データ・機能の仕様は変えず、
「伝わり方」と「見た目」の改善に限定する。

---

## K1. ルビーの獲得方法を分かりやすくする

現状、プレイヤーには「どうすればルビーが増えるか」がゲーム内で説明されておらず曖昧。
以下で、入手手段と数値をすべて明示する。数値はサーバーの実装値が正
（ログボ 3/日・7日連続ごと+10、ドロップ 撃破ごと4%・1プレイ10個・1日60個）。

1. **ガチャ画面に「ルビーの集め方」パネルを常設**する。内容（数値入りで簡潔に）:
   - 毎日ログイン: +3（7日連続ごとに +10）
   - 敵を倒すとドロップ: 4%の確率（1プレイ最大10個 / 1日最大60個）
   - ハード以上のボス戦など、スコアを送信しないモードではドロップしない
   - ★1と所持済みの会社は、ルビーではなくコインに変換される（★1 +300 / 重複 ★×300）
   - 未実装の入手手段（ランキング報酬など）は書かないこと
2. **ホームのルビー残高をタップすると内訳シートを出す**:
   現在の残高 / 今日のドロップ ○/60 / 連続ログイン ○日目（次の連続ボーナスまで あと○日）/
   本日のログインボーナス受取済みか。データは `ruby_balance` の戻り値
   （balance / drops_today / streak / bonus_today）で足りる。新規 RPC は作らない。
3. **結果画面のルビー行に源泉を添える**: 「◆ ルビー +3（ドロップ 3個）」のように
   何で増えたかを表示する。対象外モード（rdUI='na'）の結果画面には
   「このモードはルビーの対象外です」と出す。

## K2. 図鑑「サプライヤー」タブのデザイン刷新

ユーザーの要望: 画面下の大きな詳細エリアと会社の説明文（フレーバーテキスト）は不要。
その分ロゴを主役にして、全体の見栄えを上げる。スクリーンショットで確認した
現行の問題: 8列の小さいボールグリッドでロゴが読めない / 詳細カードが画面下半分を
占めて大半が空白 / 説明文が場所を取っている。

1. **一覧を 4 列のカードグリッドに変更**する。各カード:
   - 白い角丸の台座にロゴを大きく表示（カード幅いっぱい。横長ロゴは比率を保って大きく）
   - 下に社名（日本語）＋ Lv バッジ＋レアリティの★
   - レアリティで枠や背景に差をつける（★4 は紫、★5 は金/オレンジのグロー等、
     一覧のまま格が分かるように）
   - 選択中はレア色の枠＋わずかに拡大
2. **詳細は固定カードを廃止し、タップ時のボトムシートにする**:
   大きなロゴ＋社名＋★＋現在Lv の効果と次Lv の効果（NOW / NEXT）＋「ガレージへ」ボタン。
   **会社の説明文（フレーバーテキスト）は表示しない**（データ自体は消さなくてよい）。
   シートは閉じる操作（ボタン/外側タップ）で閉じる。
3. **未所持の表現を上げる**: 鍵アイコンだけではなく、ロゴのシルエット（暗く表示）
   ＋★＋「ガチャで入手」とする。
4. 上部の解放サマリー（解放 ○/28、トヨタ系 ○/6 等）は残しつつ、
   進捗バーで見栄え良くする。
5. **敵ロゴタブも同じカード様式に揃える**（ボールグリッド → カードグリッド、ロゴを大きく）。
   必殺技タブは今回の対象外だが、画面全体のトーン（余白・見出し）は合わせる。

## K3. ガレージとガチャでもロゴを主役に（様式の統一）

- ガレージのサプライヤー一覧も K2 と同じカード様式（白台座＋大きなロゴ＋社名＋Lv）に統一する。
  装備・レベルアップへの導線は現行のまま変えない。
- ガチャのラインナップ表示も同じカード様式に寄せる（結果カードの演出・大きさは現行維持）。

## 制約

- スマホ縦画面で崩れないこと。カードは指でタップしやすい大きさを保つ。
- 図鑑の解放判定・並び順・装備やレベルアップの機能仕様は変更しない。変えるのは表示だけ。
- ロゴ画像（IM）は白背景前提なので、台座は白〜明色を基本にし、ダークな画面背景との
  コントラストでロゴが浮き立つようにする。
